# Python Demo – Elzero Web School

This repository contains demo code and practice examples created while
studying **Python** from the **Elzero Web School Python Course**.

## 🎯 Purpose
The main goal of this repository is to:
- Practice Python fundamentals
- Apply concepts through small demos
- Improve problem-solving skills
- Build a solid foundation for software & data-related fields

## 📚 Topics Covered
- Variables & Data Types
- Input / Output
- Conditions (if / elif / else)
- Loops (for / while)
- Functions
- Lists, Tuples, Sets, Dictionaries
- String manipulation
- List Comprehension
- Basic problem-solving examples
